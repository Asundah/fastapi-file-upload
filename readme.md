🧪 How to Test It
1. Create the folders, paste the code, install requirements, and run uvicorn app.main:app --reload.

2. Go to http://localhost:8000.

3. Drag and drop a large image (from your phone or PC) into the box.

4. Click Upload File.

5. You will see the image preview instantly, and if you check the uploads/ folder on your laptop, you will see the image has been resized to save space.
